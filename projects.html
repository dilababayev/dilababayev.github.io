1. Swap Two Integers

Description: Write a program that swaps the values of two integers without using a third variable.


// Swap.java
public class Swap {
    public static void main(String[] args) {
        int a = 5, b = 10;
        System.out.println("Before: a = " + a + ", b = " + b);

        // Swap logic
        a = a + b;
        b = a - b;
        a = a - b;

        System.out.println("After: a = " + a + ", b = " + b);
    }
}

2. Boolean Logic Puzzle

Description: Evaluate whether (true && false) || (true || false) is true or false.

Solution: (true && false) is false, (true || false) is true → so the whole expression is false || true = true.

3. Division by Zero

Description: What happens when you divide an integer by zero in Java?

Solution: It throws an ArithmeticException. For doubles, dividing by zero gives Infinity or NaN.
