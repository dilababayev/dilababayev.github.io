1.1 — Introduction to Algorithms, Programming, and Compilers

  • Algorithm: step-by-step procedure to solve a problem.
  • Programming: expressing algorithms in a language (Java) the computer executes.
  • Compiler: translates Java source to bytecode (.class) for the JVM.
  • Java advantage: write once, run anywhere via the JVM.

1.2 — Variables and Data Types

  • Variables = named storage. Must be declared with a type.
  • Primitives: int, double, boolean, char.
  • Reference types: objects like String (variables hold references).
// declaration and initialization
int age = 17;
double score = 98.5;
boolean passed = true;
char letter = 'A';

1.3 — Expressions and Output

  • Expressions combine values, variables, and operators and evaluate to a value.
  • Operators: +, -, *, /, %.
  • Output: System.out.print() and System.out.println().
int a = 7;
int b = 2;
System.out.println(a / b);   // prints 3 (integer division)
System.out.println(a % b);   // prints 1 (remainder)
System.out.println("Sum = " + (a + b));

1.4 — Assignment Statements and Input

  • Assignment operator = stores a value in a variable.
  • Java input commonly uses Scanner from java.util.
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
System.out.print("Enter an integer: ");
int n = sc.nextInt();
sc.nextLine(); // consume newline if needed
String line = sc.nextLine();

1.5 — Casting and Range of Variables

  • Widening (implicit): smaller → larger (e.g., int → double).
  • Narrowing (explicit): requires cast, e.g., (int) 3.7 → 3.
  • Know ranges: int ~ ±2.1 billion; double has wide range but finite precision.
double d = 9;      // implicit: 9.0
int x = (int) 3.9;   // explicit cast -> 3

1.6 — Compound Assignment Operators

  • Shorthand operators modify a variable in place: +=, -=, *=, /=.
int a = 5;
a += 3; // a = 8
b *= 2; // b = b * 2

1.7 — Application Program Interface (API) and Libraries

  • API = documentation and collection of prewritten classes/methods you can reuse.
  • Common Java libraries: java.lang, java.util, etc.
  • Using APIs saves development time and reduces bugs.

1.8 — Documentation with Comments

  • Comments don't run; they explain intent for future readers.
  • Types: //, /* ... */, and /** Javadoc */.
/**
 * Returns maximum of two integers.
 * @param a first integer
 * @param b second integer
 * @return the larger value
 */
public int max(int a, int b) { return (a >= b) ? a : b; }

1.9 — Method Signatures

  • Signature = method name + parameter types (order matters).
  • Signatures are used by the compiler to resolve calls and support overloading.
public int add(int a, int b) { ... }
public double add(double a, double b) { ... } // overloaded

1.10 — Calling Class Methods

  • Class (static) methods are invoked on the class itself: ClassName.method().
  • Example: Math.sqrt(9) — no object instantiation needed.

1.11 — Math Class

  • Provides many static math utilities: sqrt, pow, abs, random.
double r = Math.sqrt(49);      // 7.0
int roll = (int)(Math.random() * 6) + 1; // 1..6

1.12 — Objects: Instances of Classes

  • Object = runtime instance of a class with fields (state) and methods (behavior).
  • Use methods to operate on object state.
Random rnd = new Random();
int value = rnd.nextInt(10); // 0..9

1.13 — Object Creation and Storage (Instantiation)

  • Create objects with new. Variables hold references, not the object content.
  • Strings have literals and constructors; literals are preferred: String s = "hi";
String s1 = new String("hello");
String s2 = "hello"; // literal; both reference equal content
MyClass obj = new MyClass();

1.14 — Calling Instance Methods

  • Instance methods are called on objects: obj.method(args).
  • Return values must be used or stored (unless void).
String name = "Dila";
int len = name.length();
String up = name.toUpperCase();

1.15 — String Manipulation

  • Strings are immutable; methods return new Strings.
  • Key methods: length(), substring(), indexOf(), equals(), compareTo(), toUpperCase().
String s = "Hello World";
int n = s.length();            // 11
String h = s.substring(0,5);   // "Hello"
int p = s.indexOf("W");       // 6
boolean eq = s.equals("hello world"); // false (case-sensitive)
